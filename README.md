# Git and GitHub Practical Exercises

## 📌 About the Project

This repository contains practical exercises to learn Git and GitHub. It covers repository creation, version control, branching, merging, remote repositories, and collaboration.

## 🎯 Objectives

* To understand Git version control.
* To learn basic Git commands.
* To manage branches and merge conflicts.
* To work with remote repositories using GitHub.
* To collaborate with multiple contributors.

## 🛠️ Technologies Used

* Git
* GitHub
* Command Line / Terminal
* Markdown

## 📚 Practical Exercises

1. **Create a Git Repository** – Initialize a local Git repository using `git init`.
2. **Create a File and Track Changes** – Create files and stage changes using `git add`.
3. **Commit Changes** – Save changes using `git commit`.
4. **View Commit History** – Display commit history using `git log`.
5. **Undo Changes** – Restore unwanted changes using Git commands.
6. **Branch Management** – Create, switch, and delete branches.
7. **Resolve Merge Conflicts** – Identify and resolve conflicts between branches.
8. **Git Stash** – Temporarily save and restore uncommitted changes.
9. **Configure a Remote Repository** – Connect a local repository to GitHub.
10. **Clone, Push, and Pull** – Synchronize changes between local and remote repositories.
11. **Fork and Pull Request** – Contribute to another repository through a pull request.
12. **Collaborative Editing** – Work with multiple contributors using GitHub.
13. **GitHub Issues and Project Boards** – Track tasks and organize project activities.

## 💻 Basic Git Commands

```bash
git init
git status
git add .
git commit -m "Initial commit"
git log --oneline
git branch
git switch main
git remote -v
git push origin main
git pull origin main
```

## ✅ Learning Outcomes

After completing these exercises, users will be able to:

* Create and manage Git repositories.
* Track and maintain changes.
* Manage branches and resolve merge conflicts.
* Connect local repositories to GitHub.
* Collaborate effectively using GitHub features.
